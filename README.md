# Convert Currency for PopClip

Source repository for the Convert Currency PopClip extension, created and maintained by Boback Shahsafdari.

The installable source package is [`Convert Currency.popclipext`](./Convert%20Currency.popclipext).

Before the first public directory submission, confirm that the permanent extension identifier in `Config.json` is the one you want to keep. PopClip Directory identifiers cannot be changed after first publication.
